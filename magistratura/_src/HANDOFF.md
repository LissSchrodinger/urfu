## Как собирается
- Скопировать `_src` в `/home/claude/mag/` (пути в build.py — `/home/claude/mag/`), `python3 build.py --inline` → `out/index.html` → `magistratura/index.html`; картинки — `magistratura/img/`.
- Части: `part_head.html` (head, CSS первого экрана, «Есть диплом», слои смены слова), `part_hero.html`, `part_herojs.js` (смена слова, варианты a–e, по умолчанию `c`, подпись стоит; `?anim=…`, `?lead=swap`), `part_rays.svg` (фон кодом), `part_rest.*`, `part_prog.css` (программы светлой таблицей как в каталоге), `hdr.html` + `hdr_tpl.html` + `hdr.js` (до `drawNav();`) + `hdr_land.css` / `hdr_land.js` (шапка каталога на лендинге), `progs2.json` (191 программа).
- Фон: `gen.py` снимает цвета 6 граней с `ref/agency_site_1440.png` в `secs.json`, `svg.py` пишет `part_rays.svg` (радиальные градиенты из точки 495,408, грани перекрыты на 0,3° от швов).
- `hdr_full.css` — правила шапки, вытащенные скриптом из `katalog/index.html` (исходник для `hdr_land.css`).
- `demo_pick.html` — переключатель вариантов анимации для показа-артефакта, в сборку сайта не входит.
